# 次元库 Windows 复刻尝试（残次品）

> **项目状态：残次品 / 未完成原型。当前不是正式完成版本，存在兼容性、稳定性和体验缺口。样例测试通过不代表整体可用。**
这是一次把次元库 2.6.5 的部分功能重建到 Windows 的尝试。**先上传保存当前状态，后续再修，不把它当成已经完成的复刻。**

## 下载

到 [预览版下载页面](https://github.com/37f/CiyuanWindowsReplica/releases/tag/v0.1.0-prototype) 取用 Windows x64 便携包或完整源码包。

完整解压便携包后，双击 `次元库 Windows 复刻版.exe`，保留同目录 DLL 和 `ui` 文件夹。需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime；不需要原 APK、安卓模拟器或 REA。

## 已知缺口

- 主要只适配了 AGE 动漫和 Mwai 普通漫画的部分链路，**108 条来源配置不等于 108 个来源能用**。
- 来源、作品及播放线路可能失效。部分样例线路出现 HTTP403、404 或不可用提示片。
- 封面来源可能拒绝请求，界面会出现占位图。
- 界面与日常操作体验仍粗糙，只覆盖部分核心流程，不能视为完整还原原 App。
- 网页播放兼容没有逐站验收；正常登录、验证码及会员条件仍由来源站决定。
- 不含原 App 的广告任务、支付、社区、云端同步、DLNA 和安卓超分辨率。

详细记录见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)、[功能与来源对照](功能与来源对照.md) 和 [使用说明](使用说明.md)。

## 当前代码

代码包含本地蓝白/深色界面、搜索与分类、详情选集、HLS/部分直链播放、漫画阅读、收藏和历史，以及独立本机数据目录。

此前少量本机样例跑通过视频、漫画、翻页及续播，也通过了34项离线检查。**这些记录只说明对应样例和测试当时通过，不构成完整性、稳定性或日常普遍可用的保证。** 发布状态按“残次品 / 未完成原型”处理。

## 构建

在 Windows PowerShell 中执行：

```powershell
.\build.ps1
.\test-all.ps1
& '.\build\次元库 Windows 复刻版.exe'
```

构建结果在 `build/`。固定的最小依赖随仓库提供，见 [DEPENDENCIES.md](DEPENDENCIES.md)。个人记录默认在 `%LOCALAPPDATA%\CiyuanWindowsReplica`。
